# 지혜의 작업실

https://jihye84.github.io/

깃헙에 올린 웹 작품들을 여섯 서랍(빛과 무늬 · 소리와 음악 · 1학년 한글 · 1학년 수학 · 지도와 세계 · 배움의 서재)으로 나누어 소개하는 페이지입니다.

- 작품 목록과 소개글은 `works.js` 한 파일에 모여 있어요. 새 작품은 해당 분야의 `works` 배열에 한 줄을 더하면 됩니다.
- 어느 기기·창 크기에서도 스크롤 없이 한 화면에 맞춰지고, 카드가 넘치면 쪽을 넘겨(밀어서) 봅니다.
- 오른쪽 위 "한 / EN" 버튼으로 영어 버전을 볼 수 있어요. 영어권 브라우저에서는 처음부터 영어로 열리고, 주소 뒤에 `?lang=en`을 붙여 영어 화면을 바로 공유할 수도 있어요.
- 카카오톡·네이버·페이스북 등 인앱 브라우저에서 열면 기본 브라우저로 다시 열립니다.
